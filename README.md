# Žalias kampas

Vieno puslapio lietuviška augalų ir kavos kavinės Kaune verslo idėjos svetainė. Prisitaiko prie telefono ekrano, sukurta tik su HTML, CSS ir JavaScript, be bibliotekų ar išorinių išteklių.

## Failai ir paleidimas

- `index.html` – visos svetainės skiltys ir iliustracija.
- `style.css` – stiliai ir prisitaikymas prie ekranų.
- `script.js` – demonstracinės formos padėka ir poraštės metai.

Atidarykite `index.html` naršyklėje. Diegimo ir kompiliavimo nereikia.

## GitHub Pages

Įkelkite šiuos tris failus ir README.md į `main` šakos šakninį aplanką. Saugyklos **Settings → Pages → Build and deployment** pasirinkite **Deploy from a branch**, šaką **main** ir aplanką **/ (root)**, tada **Save**. Svetainės adresą pateiks GitHub Pages. Santykinės failų nuorodos tinka ir projekto saugyklos adresui.

## Demonstracinis turinys

Meniu ir kainos pavyzdiniai. Visi trys atsiliepimai aiškiai pažymėti kaip pavyzdiniai. Tikslus adresas ir darbo laikas dar nenurodyti. Mygtukas „Rezervuoti staliuką“ nuveda į kontaktų formą, tačiau ji tik parodo padėką: žinučių nesiunčia, duomenų nesaugo ir rezervacijų neatlieka.
